# RBL 0.8.0 — руководство для начинающих

> **Версия руководства: RBL 0.8.0.**
> Руководство описывает языковой и runtime-контракт RBL **0.8.0**, включая ограниченные спецификаторы форматирования f-строк. Полная спецификация приведена в справочниках.

---

## 1. Что такое RBL и кому подойдёт это руководство

RBL (ReiwaBatLanguage) — компилируемый язык программирования с собственным синтаксисом, frontend, генерацией assembly и runtime. В этой версии программы пишутся в исходных файлах `.rbl`, а запускаются через CLI из репозитория.

Этот гайд рассчитан на два типа читателей:

- **Новичок в программировании.** Можно идти последовательно, начиная с урока 1. Потребуется время, чтобы освоить сами понятия переменных, циклов, функций и коллекций.
- **Человек, знакомый с Python или другим языком.** Можно быстро пройти первые уроки и использовать справочные разделы ниже как карту различий и возможностей RBL.

### Можно ли дать RBL человеку, который знает Python?

**Да. Человек, который уже понимает переменные, условия, циклы, функции, списки и словари в Python, с высокой вероятностью сможет самостоятельно разобраться с базовым RBL по этому руководству, двадцати примерам и ссылкам на документацию.** Ему не придётся заново изучать основы программирования — в основном нужно освоить другой синтаксис и несколько важных отличий runtime.

Но «знает немного Python» бывает разным. Если человек только писал простые скрипты и ещё не понимает функции, изменяемость объектов или области видимости, лучше пройти курс по порядку. Если он уже самостоятельно писал небольшие программы, двадцать примеров и справочные разделы должны дать достаточную основу для чтения и написания небольших RBL-программ.

Это не обещание, что одного README достаточно для освоения вообще всех деталей языка. Для уверенной работы нужно читать исходники примеров, запускать их, менять код, пользоваться справочником синтаксиса и проверять поведение через `rbl.py check` и `rbl.py run`.

### Что важно знать до начала

- RBL 0.8.0 — не Python с переименованными ключевыми словами. Синтаксис похож на некоторые знакомые конструкции, но блоки, объявления переменных и часть семантики отличаются.
- Примеры курса написаны на **RBL**. Python используется только как способ запустить файл `rbl.py` — это CLI-инструмент проекта, а не язык примеров.
- Все встроенные функции и пространства имён стандартной библиотеки доступны без `import`.
- В этой версии нет пользовательских `import`, пакетного менеджера и компиляции нескольких исходных файлов в одну программу.

## 2. Установка и запуск

Предполагается, что репозиторий RBL уже скачан, а команды выполняются из его корневой папки. CLI — это файл `rbl.py`; он не устанавливает глобальную команду `rbl` в систему.

Проверьте окружение:

**Windows PowerShell**

```powershell
python rbl.py doctor
python rbl.py version
```

**Linux / WSL**

```bash
python3 rbl.py doctor
python3 rbl.py version
```

`doctor` проверяет доступность выбранного backend и необходимых инструментов. Для Linux нужны GNU assembler и linker. Нативная сборка Windows использует MinGW-w64; также можно использовать WSL. Подробности — в [руководстве по Windows и WSL](../../docs/ru/how-to/windows-toolchain.md).

### Проверить и запустить первую программу

```bash
python3 rbl.py check examples/beginner/01_hello_variables.rbl
python3 rbl.py run examples/beginner/01_hello_variables.rbl
```

Windows PowerShell:

```powershell
python rbl.py check examples/beginner/01_hello_variables.rbl
python rbl.py run examples/beginner/01_hello_variables.rbl
```

- `check` проверяет исходник, выполняет frontend/analysis/codegen, но не запускает assembler и linker и не создаёт исполняемый файл.
- `run` собирает и запускает программу.
- `build` собирает исполняемый файл без запуска.
- `asm` показывает сгенерированный assembly.

## 4. Как устроена программа RBL

Минимальная программа:

```rbl
func main() (
    print("Hello, RBL!")
)
```

- `func` объявляет функцию.
- `main` — точка входа; она должна быть без параметров.
- `()` после имени функции содержит список параметров. Здесь он пустой.
- `(` и `)` вокруг тела функции обозначают блок. В RBL блоки не оформляются фигурными скобками.
- `print(...)` выводит значения в терминал.

Программа может содержать объявления функций и `struct`. В RBL 0.8.0 один исходный файл компилируется как одна программа.

### Комментарии

Обе формы — однострочные:

```rbl
// Комментарий в стиле C++
# Комментарий в стиле Python
```

Комментарии полезны для пояснения намерений кода. Они не меняют поведение программы.

## 5. Переменные, типы и значения

### `set` и `let`

```rbl
set score = 10
let score = 15
let score += 5
let score *= 2
let score++
let score--
```

- `set name = value` **создаёт** новую переменную.
- `let name = value` **изменяет** уже объявленную переменную.
- Повторный `set` с тем же именем — ошибка.
- `let` для неизвестного имени — ошибка.
- Обычное изменение требует, чтобы runtime-тип нового значения совпадал с типом текущего значения.
- Для обычной переменной-идентификатора с `let` доступны `+=`, `-=`, `*=`, `/=`, `%=` и формы инкремента/декремента `name++`, `name--`, `++name`, `--name` (с `let`, например `let ++name`). Эти сокращённые формы не работают с элементами списков (`values[0]`) или полями структур (`point.x`): для них используйте обычное присваивание через `let`.

Важное отличие от Python: в RBL нельзя просто написать `x = 5`, чтобы объявить или изменить переменную. Используйте `set` или `let`.

### Типы, которые встречаются в RBL 0.8.0

| Тип / значение | Что означает |
|---|---|
| `int` | Знаковое целое число шириной 64 бита. Проверяемые целочисленные операции сообщают об ошибке переполнения. |
| `float` | Число с плавающей точкой IEEE-754 binary64. |
| `string` | Строка UTF-8. В runtime используется NUL-terminated представление. |
| `bool` | Логическое значение `true` или `false`. |
| `null` | Отдельное значение `null`. |
| `Unit` | Отсутствие полезного результата; его возвращает функция без возвращаемого значения. |
| list | Изменяемый индексируемый список. |
| dictionary | Изменяемое отображение ключей в значения. |
| tuple | Упорядоченная неизменяемая последовательность. |
| struct instance | Экземпляр структуры; фактически представлен словарём полей. |

RBL хранит значения динамически, но позволяет объявлять типы параметров функций и проверяет их при вызове. Для обычных локальных переменных аннотации вида `x: int` нет: тип определяется значением при `set`.

`Unit` и `null` — не одно и то же. Пустой кортеж `()` также не следует путать с `Unit`.

### Числовые и логические литералы

```rbl
set decimal = 17
set million = 1_000_000
set hexadecimal = 0xFF
set binary = 0b1010
set octal = 0o755
set fraction = 1.5
set scientific = 1.5e-3
set old_float_form = 10f
set enabled = true
set missing = null
```

Ведущий ноль не делает число восьмеричным: `017` — десятичное число. Для восьмеричного литерала нужен префикс `0o`. Подчёркивания в числах служат разделителями. Форма с суффиксом `f` сохранена для float-литералов.

## 6. Операторы и выражения

### Арифметика

| Оператор | Действие |
|---|---|
| `+` | Сложение; также объединение двух строк. |
| `-` | Вычитание. |
| `*` | Умножение. |
| `/` | Деление двух `int` даёт `int` с усечением к нулю; деление двух `float` даёт `float`. Смешивать `int` и `float` нельзя. |
| `%` | Остаток целочисленного деления; оба операнда должны быть `int`. |

Примеры:

```rbl
set sum = 7 + 3
set difference = 7 - 3
set product = 7 * 3
set quotient = 7 / 2
set float_quotient = 7.0 / 2.0
set remainder = 7 % 3
set greeting = "Hello, " + "RBL"
```

Целочисленное деление усекается к нулю: `7 / 2` даёт `3`. Если оба операнда — `float`, результат тоже `float`: `7.0 / 2.0` даёт `3.5`. **Смешанные пары `int`/`float` не поддерживаются**: `7.0 / 2` и `7 / 2.0` вызывают runtime error. Остаток имеет знак делимого: `-10 % 3` даёт `-1`. Для остатка от деления `float` используйте глобальную функцию `fmod(a, b)`. Деление и остаток на ноль вызывают runtime error.

### Сравнения и логика

- Сравнения: `==`, `!=`, `<`, `>`, `<=`, `>=`.
- Логика: `and`, `or`, `not`; `!` — альтернативная запись `not`.
- `==` проверяет равенство, `is` — идентичность значения/объекта.

**Особенность:** `and` и `or` в RBL 0.8.0 не используют short-circuit evaluation. Оба операнда вычисляются. Поэтому не помещайте в правую часть выражение, которое нельзя безопасно вычислять при любом результате левой части.

Условное выражение поддерживается:

```rbl
set score = 12
set message = "доступ разрешён" if (score >= 10) else "доступ запрещён"
```

Вычисляется только выбранная ветвь. `if` в такой форме пишется на той же строке.

## 7. Условия и `switch`

```rbl
set temperature = 18

if (temperature >= 25) (
    print("Тепло")
) elif (temperature >= 10) (
    print("Прохладно")
) else (
    print("Холодно")
)
```

`if` проверяет первое условие; `elif` добавляет следующие проверки; `else` выполняется, если ни одно предыдущее условие не подошло.

`switch` выбирает ветвь по значению:

```rbl
set code = 2
switch (code) (
    case 1 ( print("Один") )
    case 2, 3 ( print("Два или три") )
    case 4..=9 ( print("От четырёх до девяти") )
    default ( print("Другое значение") )
)
```

`case` поддерживает несколько значений через запятую и диапазоны. `default` — запасная ветвь. В качестве subject у `switch` допускается переменная или литерал; произвольное выражение с побочным эффектом использовать нельзя.

## 8. Циклы

### Диапазоны

```rbl
for (i in 0..5) (
    print(i)
)

for (i in 0..=5) (
    print(i)
)
```

- `0..5` — от `0` до `4`: правая граница не включается.
- `0..=5` — от `0` до `5`: правая граница включается.

### Обход списка

```rbl
set names = ["Ada", "Grace", "Edsger"]
for (name in names) (
    print(name)
)
```

Форма `for (item in source)` поддерживает диапазон или список. Общего обхода словарей в цикле в 0.8.0 нет.

### Условный цикл

```rbl
set counter = 0
for (counter < 3) (
    print(counter)
    let counter++
)
```

`for (condition)` повторяет тело, пока условие истинно. Это не синтаксис `for` из Python: здесь нет трёх частей заголовка.

### `break`, `continue` и вложенные циклы

```rbl
for (row in 0..3) (
    for (column in 0..3) (
        if (column == 1) ( continue )
        if (row == 2) ( break )
        print(row, column)
    )
)
```

- `break` завершает ближайший окружающий цикл.
- `continue` пропускает остаток текущей итерации ближайшего цикла.
- Вложенные циклы поддерживаются.
- `break` и `continue` вне цикла — ошибки.

Переменная цикла по диапазону остаётся доступной после цикла, если была хотя бы одна итерация. Если диапазон не дал ни одной итерации, переменная цикла не появляется. Блоки не создают отдельную локальную область видимости.

## 9. Функции и рекурсия

```rbl
func add(a int, b int) int (
    return a + b
)

func greet(name string) (
    print("Привет,", name)
)

func main() (
    set result = add(20, 22)
    greet("RBL")
    print(result)
)
```

Объявление начинается с `func`. Тип параметра указывается **после** имени параметра: `a int`. Возвращаемый тип, если он указан, пишется после закрывающей скобки параметров: `) int (`. `return` возвращает значение. Функция без возвращаемого значения даёт `Unit`.

Типы параметров проверяются при вызове. Аннотация возвращаемого типа разбирается, но в 0.8.0 не проверяется runtime как строгий контракт. Перегрузки функций по сигнатуре нет. Если одно имя функции объявлено повторно, используется последнее определение. Именованных, необязательных и variadic-параметров нет.

### Рекурсия

Рекурсивные вызовы поддерживаются:

```rbl
func factorial(n int) int (
    if (n <= 1) (
        return 1
    )
    return n * factorial(n - 1)
)

func main() (
    print(factorial(5))
)
```

У рекурсивной функции должно быть условие остановки. Пример показывает синтаксис, но не означает, что runtime предоставляет неограниченную глубину рекурсии.

## 10. Списки

```rbl
set values = [10, 20, 30]
print(values[0])
let values[1] = 25
print(len(values))
print(20 in values)
```

- Список записывается в квадратных скобках: `[a, b, c]`.
- Индексация начинается с нуля.
- Список изменяемый; элемент можно заменить через `let list[index] = value`.
- Списки могут быть вложенными и содержать значения разных типов.
- `len(list)` возвращает число элементов.
- `in` проверяет непосредственные скалярные элементы списка/кортежа. Это не рекурсивный поиск внутри вложенных контейнеров. Для строк `in` проверяет наличие подстроки.
- `==` сравнивает содержимое контейнеров глубоко; для словарей порядок ключей не влияет на равенство. `is` проверяет идентичность, а не равенство.

Пример вложенного списка:

```rbl
set matrix = [[1, 2], [3, 4]]
print(matrix[0][1])
```

В 0.8.0 нет отрицательной индексации, срезов и конкатенации списков оператором `+`.

## 11. Словари и вложенные словари

```rbl
set profile = {"name": "Mira", "level": 3}
print(profile["name"])
let profile["level"] = 4
print("level" in profile)
print(len(profile))
```

Словарь хранит пары «ключ — значение». Поддерживаемые типы ключей: `int`, `float`, `string` и `bool` (`true` / `false`). Оператор `in` для словаря проверяет **наличие ключа**, а не значения.

```rbl
set settings = {
    "video": {"width": 1920, "height": 1080},
    "audio": {"volume": 80}
}
print(settings["video"]["width"])
```

Вложенные словари можно читать через цепочку индексов. Общего цикла по элементам словаря нет.

Если ключ отсутствует, чтение возвращает `Unit` (`()`), а не `null`. Для проверки ключа сначала используйте `in`. Словари сравниваются по содержимому без учёта порядка ключей. Порядок печати словаря не является гарантированным.

## 12. Кортежи

```rbl
set position = (12, 25)
print(position[0])
print(len(position))
```

- `(a, b)` создаёт кортеж.
- `()` — пустой кортеж.
- `(value)` — группировка выражения, а не одноэлементный tuple.
- Кортеж поддерживает индексацию, `len`, вывод и глубокое равенство.
- Элементы кортежа нельзя переназначить.

Распаковка кортежа в переменные (tuple destructuring) не реализована.

## 13. Структуры и методы с receiver

```rbl
struct Point (
    x int
    y int
)

func (p Point) move(dx int, dy int) (
    let p.x = p.x + dx
    let p.y = p.y + dy
)

func main() (
    set point = Point(3, 4)
    point.move(1, 2)
    print(point.x, point.y)
)
```

- `struct` объявляет набор именованных полей.
- Структура должна быть объявлена до использования.
- Конструктор получает по одному позиционному аргументу на поле, в порядке объявления.
- Метод с receiver записывается как `func (receiver Type) name(...) (...)`.
- Вызов `point.move(...)` преобразуется в обычный вызов функции, где `point` — первый аргумент.

Это **не полноценные классы**: экземпляр `struct` в runtime представлен словарём. Отдельной runtime-идентичности struct, наследования и полноценной объектной системы нет. Именованного создания полей конструктора (например, `Point(x: 1, y: 2)`) нет.

## 14. Строки

### Обычные строки, конкатенация и f-строки

```rbl
set language = "RBL"
set message = "Hello, " + language
print(message)
print(f"Welcome to {language}!")
print(f"Braces: {{ and }}")
```

`+` объединяет строки. F-строки поддерживают интерполяцию выражений, экранирование фигурных скобок двойными `{{` и `}}`, а также ограниченные спецификаторы форматирования.

```rbl
set value = 42
set pi = 3.14159
set language = "RBL"
print(f"integer: [{value:>8d}]")
print(f"fixed:   [{pi:.2f}]")
print(f"fill:    [{language:*^10s}]")
```

Спецификатор может задавать заполнение и выравнивание, минимальную ширину, точность float и тип преобразования (`d`, `b`, `o`, `x`, `X`, `f`, `e`, `g`, `s`). Полная грамматика, пределы и неподдерживаемые комбинации описаны в [справочнике синтаксиса](../../docs/ru/reference/syntax.md).

### Escape-последовательности

Поддерживаются:

| Escape | Значение |
|---|---|
| `\\n` | Перевод строки. |
| `\\t` | Табуляция. |
| `\\r` | Возврат каретки. |
| `\\\\` | Обратная косая черта. |
| `\\"` | Кавычка. |
| `\\xNN` | Символ по двум шестнадцатеричным цифрам. |
| `\\uXXXX` | Unicode escape из четырёх шестнадцатеричных цифр. |
| `\\UXXXXXXXX` | Unicode escape из восьми шестнадцатеричных цифр. |

Escape `\\0` запрещён: runtime использует NUL-terminated строки.

### Многострочные строки

Тройные кавычки позволяют записывать строку на нескольких строках:

```rbl
set description = """Это первая строка.
Это вторая строка.
Это третья строка."""
print(description)
```

### Функции `rbl.string`

| Функция | Назначение |
|---|---|
| `rbl.string.len(text)` | Число UTF-8 code points в строке. |
| `rbl.string.upper(text)` | Перевод ASCII-букв в верхний регистр. |
| `rbl.string.lower(text)` | Перевод ASCII-букв в нижний регистр. |
| `rbl.string.trim(text)` | Удаление пробелов, tab, LF и CR по краям. |
| `rbl.string.contains(text, part)` | Проверка наличия подстроки. |
| `rbl.string.starts_with(text, prefix)` | Проверка префикса. |
| `rbl.string.ends_with(text, suffix)` | Проверка суффикса. |

`upper` и `lower` работают только с ASCII-буквами; это не Unicode case conversion. Строки хранятся в UTF-8, а `len` считает Unicode code points, не байты.

## 15. Ввод, вывод и работа с файлами

### Терминал

```rbl
print("Введите имя:")
set name = input("Имя: ")
print("Привет,", name)
```

- `print(value, ...)` выводит аргументы через пробел и добавляет перевод строки.
- `input()` читает одну строку стандартного ввода.
- `input(prompt)` выводит prompt, flush-ит его и читает строку.
- `input` возвращает `string`. Для чисел используйте `int(...)` или `float(...)`.

### Файлы

```rbl
set contents = read_file("notes.txt")
write_file("copy.txt", contents)
```

Или через namespace:

```rbl
set contents = rbl.io.read_file("notes.txt")
rbl.io.write_file("copy.txt", contents)
```

| Функция | Назначение |
|---|---|
| `read_file(path)` / `rbl.io.read_file(path)` | Читает текстовый файл. |
| `write_file(path, content)` / `rbl.io.write_file(path, content)` | Записывает текстовый файл. |
| `rbl.fs.exists(path)` | Проверяет существование пути. |
| `rbl.fs.delete(path)` | Удаляет файл/путь и возвращает признак успеха. |
| `rbl.fs.cwd()` | Возвращает текущий рабочий каталог. |

Пути и текущий каталог зависят от операционной системы и способа запуска. `cwd()` не следует сравнивать как одинаковую строку между Windows и Linux.

## 16. Стандартная библиотека: полный обзор доступных имён

Встроенные функции доступны напрямую. Для namespace-функций не требуется `import`; это не означает, что в языке есть система пользовательских модулей.

### Глобальные встроенные функции

| Имя | Назначение |
|---|---|
| `print(value, ...)` | Вывод значений через пробел с переводом строки. |
| `len(value)` | Длина строки в UTF-8 code points или число элементов list/dictionary/tuple. |
| `input()` / `input(prompt)` | Чтение строки из stdin, с prompt или без него. |
| `read_file(path)` | Чтение текстового файла. |
| `write_file(path, content)` | Запись текстового файла. |
| `abs(x)` | Абсолютное значение. |
| `sqrt(x)` | Квадратный корень. |
| `min(x, ...)`, `max(x, ...)` | Минимум/максимум числовых аргументов общего типа. |
| `int(x)`, `float(x)`, `str(x)` | Преобразования поддерживаемых скалярных значений. |
| `pow`, `floor`, `ceil`, `round` | Степень и округление. |
| `sin`, `cos`, `tan` | Тригонометрические функции; аргументы в радианах. |
| `log`, `log10`, `log2`, `exp` | Логарифмы и экспонента. |
| `random_int(a, b)` | Псевдослучайное целое в включительном диапазоне. |
| `random_float()` | Псевдослучайное число `float` в `[0, 1]`. |
| `random_bool()` | Псевдослучайное `bool`. |
| `trunc`, `fmod`, `hypot` | Усечение, float remainder, гипотенуза. |
| `degrees`, `radians` | Преобразование градусов и радиан. |
| `clamp`, `sign` | Ограничение числового значения диапазоном и знак числа. |
| `is_nan`, `is_inf` | Проверка NaN и бесконечности. |

### Namespace `rbl.math`

Реализованные методы namespace: `abs`, `sqrt`, `pow`, `min`, `max`, `floor`, `ceil`, `round`, `sin`, `cos`, `tan`, `log`, `exp`, `log10`, `log2`, `trunc`, `sign`, `is_nan`, `is_inf`.

Константы: `rbl.math.pi` и `rbl.math.e` — значения, не функции; они доступны только через пространство имён `rbl.math`, а не как глобальные имена. Для них не нужны круглые скобки.

Важно: `fmod`, `hypot`, `degrees`, `radians` и `clamp` доступны как глобальные функции, но не как методы `rbl.math` в реализации 0.8.0. В частности, вызов `rbl.math.clamp(...)` приводит к unknown-method runtime error; используйте `clamp(...)`. Некоторые записи в отдельном справочнике standard library шире фактического набора namespace-методов — здесь приведён именно реализованный набор.

### Namespace `rbl.io`

- `rbl.io.input()`
- `rbl.io.prompt(text)`
- `rbl.io.read_file(path)`
- `rbl.io.write_file(path, content)`

### Namespace `rbl.random`

- `rbl.random.int(min, max)` — включительный диапазон.
- `rbl.random.float()` — значение в `[0, 1]`.
- `rbl.random.bool()` — случайное логическое значение.

### Namespace `rbl.fs`

- `rbl.fs.exists(path)`
- `rbl.fs.delete(path)`
- `rbl.fs.cwd()`

### Namespace `rbl.time`

- `rbl.time.now_ms()` — миллисекундное значение часов платформы.
- `rbl.time.sleep_ms(duration)` — приостановка на неотрицательное количество миллисекунд.

**Платформенная оговорка:** `now_ms()` реализован по-разному. Linux использует `CLOCK_REALTIME` (настенные часы), Windows — `GetTickCount64()` (монотонное время с момента загрузки). Значения и семантика между платформами несопоставимы. Не используйте этот API как переносимый абсолютный timestamp или универсальный benchmark timer.

### Логирование

```rbl
warn.log("Сообщение-предупреждение")
error.log("Сообщение-об-ошибке")
```

Выводятся сообщения с префиксами `[WARN]` и `[ERROR]`. Это два доступных logging method в описанном API, а не полноценная настраиваемая logging-система.

### Случайные числа: важное ограничение

Генератор псевдослучайный и **не криптографически безопасный**. Linux использует C library `rand()`, Windows — внутренний linear congruential generator. Последовательности между платформами не совпадают. Не используйте эти функции для паролей, токенов, ключей и других секретов.

Это важный раздел: не стоит переносить в RBL возможности Python или других языков, если их нет в текущем frontend/runtime.

| Возможность | Статус в 0.8.0 |
|---|---|
| `import`, пользовательские модули, multi-file compilation | Нет. Один исходный файл на программу. |
| Глобальные переменные и константы | Нет. |
| Исключения: `try`, `catch`, `finally`, `raise` | Нет. |
| `defer` | Нет. |
| Lambda и closures | Нет. |
| Named, default и variadic arguments | Нет. |
| Перегрузка функций | Нет. |
| Async/await и task scheduler | Нет. |
| Generics и развитая статическая типовая система | Нет. |
| Nullable type annotations | Нет. |
| Полноценные классы, наследование и отдельная runtime identity struct | Нет. |
| Named struct construction | Нет. |
| Tuple destructuring | Нет. |
| Срезы и отрицательная индексация списков | Нет. |
| Общая итерация словарей в `for` | Нет. |
| Конкатенация списков через `+` | Нет. |

Также учитывайте runtime-ограничения: `upper/lower` работают только с ASCII; PRNG не криптографический; `cwd` и источник часов платформозависимы; строки, выделенные текущими runtime-путями, не освобождаются индивидуально до завершения процесса.

Полный список поддерживается в [ограничениях RBL 0.8.0](../../docs/ru/reference/limitations.md).

## 20. Сможет ли Python-разработчик разобраться самостоятельно?

Практическая оценка:

| Опыт человека | Ожидаемый результат |
|---|---|
| Только видел Python и знает несколько команд | Сможет читать простые примеры с подсказками, но базовые понятия придётся изучать отдельно. |
| Писал небольшие скрипты: переменные, `if`, циклы, функции | Должен освоить базовый RBL по двадцати урокам и этому гайду. |
| Уверенно использует списки, словари, функции, файлы и отладку в Python | Должен самостоятельно освоить основную часть RBL 0.8.0; главная работа — привыкнуть к синтаксису и отличиям runtime. |
| Опытный Python-разработчик | Сможет быстро читать язык, но не должен предполагать, что в RBL есть все привычные возможности Python. |

### Самые важные различия с Python

| Python | RBL 0.8.0 |
|---|---|
| `x = 10` | `set x = 10` |
| `x = 20` для изменения | `let x = 20` |
| `def main():` | `func main() (` и закрывающая `)` |
| Отступы задают блок | Блок задаётся круглыми скобками; отступы сами по себе не создают scope. |
| `for i in range(5):` | `for (i in 0..5) (` |
| `while condition:` | `for (condition) (` |
| `elif` | `elif` |
| `dict` | Похожий словарь, но нет общего `for key, value in dict.items()`. |
| `None` | `null` и отдельное значение `Unit`. |
| `and` / `or` с short-circuit | `and` / `or` вычисляют оба операнда. |
| `f"{x:.2f}"` | Поддерживаются ограниченные спецификаторы форматирования; dynamic/nested specs не поддерживаются. |
| `import module` | Пользовательских source imports нет; встроенные namespace доступны напрямую. |

**Вывод:** человек с практическими знаниями Python — подходящая аудитория для этого гайда. Он сможет понять синтаксис и самостоятельно читать примеры. Но для написания нетривиального кода ему обязательно нужно запомнить ограничения RBL, а не механически переносить Python-код.

5. Прочитать [справочник стандартной библиотеки](../../docs/ru/reference/standard-library.md).
6. Изучить [ограничения языка](../../docs/ru/reference/limitations.md), чтобы не искать несуществующие конструкции.
7. Посмотреть остальные [примеры RBL](../README.md), особенно алгоритмы и симуляции.
8. Проверять свои программы через `check`, а запускать через `run`.

### Небольшие практические задания

1. Измените урок 1: объявите ещё три переменные разных типов.
2. В уроке 2 добавьте вычисление остатка `%`; не делите на ноль.
3. В уроке 3 добавьте ветвь `case` и проверьте несколько значений.
4. В уроке 4 сделайте вложенный цикл и посчитайте сумму чисел.
5. В уроке 5 напишите рекурсивную функцию с условием остановки.
6. В уроке 6 создайте список списков и прочитайте один внутренний элемент.
7. В уроке 7 создайте словарь, содержащий другой словарь.
8. В уроке 8 добавьте поле в `struct` и обновите его через `let`.
9. В уроке 9 попробуйте тройную строку, escape-последовательности и ширину/точность f-строки.
10. В уроке 10 изучите стандартную библиотеку, а затем выполните уроки 11–20: каждый посвящён отдельной возможности языка.
