# RBL 0.7 syntax changes

RBL 0.7 makes parentheses the canonical block delimiter. A block is opened and closed with `(` and `)` just like a function parameter list.

## Functions

```rbl
func add(a int, b int) int (
    return a + b
)

func main() (
    print(add(2, 3))
)
```

## Conditions

A condition keeps its own parentheses, followed by the block parentheses:

```rbl
if (x > 10) (
    print("big")
) elif (x == 10) (
    print("exact")
) else (
    print("small")
)
```

The double-parenthesis shape is intentional: the first pair is expression grouping, the second pair is the statement block.

## Loops

```rbl
for (i in 0..5) (
    print(i)
)

for (i in 0..=5) (
    print(i)
)
```

`..` is exclusive and `..=` is inclusive.

## Parentheses are now the style default

The formatter, IDE indentation logic, examples and project templates emit the parenthesized form.

For compatibility, the parser still accepts old `{ ... }` blocks, but they are legacy syntax and should not be generated by new code.
