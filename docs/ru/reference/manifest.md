## Reference: `rbl.toml`

Манифест проекта — TOML-файл `rbl.toml` в каталоге проекта. Текущий CLI читает поля `name`, `version` и `entry` в секции `[package]`.

## Формат

```toml
[package]
name = "my_app"
version = "0.1.0"
entry = "src/main.rbl"
```

| Поле | Обязательность / default | Значение |
|---|---|---|
| `package.name` | Необязательно для разрешения entry; создаётся CLI при `new/init` | Имя проекта. |
| `package.version` | Необязательно для разрешения entry; создаётся CLI при `new/init` | Версия пользовательского проекта. |
| `package.entry` | По умолчанию `src/main.rbl` | Путь к стартовому исходнику относительно каталога проекта. |

Версия нового проекта по умолчанию — `0.1.0`; это не версия самого языка/компилятора RBL. Версия RBL находится в корневом файле `VERSION` репозитория.

## Разрешение entry

Из каталога проекта:

1. Явно переданный путь к исходнику имеет приоритет над манифестом.
2. Если путь не передан, используется `package.entry`.
3. Если ключ `entry` отсутствует, используется `src/main.rbl`.
4. Если выбранный файл отсутствует, но существует `main.rbl` в корне проекта, используется этот файл.

## Чего манифест пока не делает

CLI не разрешает зависимости, не загружает пакеты, не выполняет lockfile resolution и не компилирует импортируемые source modules. Поля для зависимостей, targets и package registry в этой версии не являются частью реализованного контракта.
