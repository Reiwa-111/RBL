# Урок 5: управляемые строки внутри контейнеров

Списки и словари могут хранить ссылки на динамические строки. Сборщик Runtime проходит по поддерживаемым ссылкам контейнеров, поэтому строка внутри достижимого списка или словаря тоже остаётся достижимой.

```rbl
func main() (
    set labels = ["lexer", "parser", "codegen"]
    set details = {"release": "0.8.1", "abi": "1.2.0"}
    set release = details["release"]
    set title = f"RBL {release}"
    let labels[1] = title
    print(labels[0], labels[1], labels[2])
)
```

Сборка мусора выполняется автоматически. Safe points, генерируемые компилятором, пропускаются в доказанно неаллоцирующих быстрых циклах, но сохраняются там, где возможна аллокация или изменение корней указателей. Это внутренняя оптимизация, а не переключатель управления памятью для пользователя.

Запусти `examples/v081/05_managed_string_collections.rbl` и `06_managed_string_workload.rbl`. Это функциональные примеры, а не бенчмарки.

**Упражнение:** храни сгенерированные подписи во вложенном списке и проверь, что последующее чтение возвращает правильный текст.
