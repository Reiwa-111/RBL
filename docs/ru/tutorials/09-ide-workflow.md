# Урок 9: рабочий процесс native IDE и диагностика

Основной frontend 0.8.1 написан на C++20 + wxWidgets 3.2 + Scintilla. Rust worker работает отдельно через ограниченный NDJSON protocol. Редактор открывает обычные текстовые файлы с любыми расширениями, но compiler actions намеренно ограничены файлами `.rbl`.

Полезные сочетания: `Ctrl+O` открыть файл, `Ctrl+Shift+O` открыть папку проекта, `Ctrl+F` поиск, `Ctrl+H` замена, `Ctrl+Shift+F` поиск по файлам, `Ctrl+P` Quick Open, `Ctrl+Shift+P` command palette, `F7` check, `F5` run, `Ctrl+B` build, `Shift+F5` stop.

Панели Problems/Console/Run можно перемещать. Нажатие на диагностику открывает исходник и переносит каретку к указанной позиции. Для project tree и Find in Files заданы лимиты обхода и результатов; это защитные ограничения, а не случайные баги.

**Упражнение:** открой проект, выполни Check для `.rbl`, внеси ошибку и перейди к диагностике. Затем открой `.md` и проверь, что его можно редактировать, но нельзя передать в Run/Build.
