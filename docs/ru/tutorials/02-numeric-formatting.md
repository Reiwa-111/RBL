# Урок 2: системы счисления и форматы float

Преобразования `d`, `b`, `o`, `x` и `X` выводят целые числа в десятичной, двоичной, восьмеричной и шестнадцатеричной системах. Префиксы `0b`, `0o` и `0x` автоматически не добавляются. Для float доступны `f`, `e` и `g`, а также варианты в верхнем регистре.

```rbl
func main() (
    set value = 255
    set pi = 3.1415926535
    print(f"{value:d} {value:b} {value:o} {value:X}")
    print(f"fixed={pi:.3f}")
    print(f"scientific={pi:.2e}")
    print(f"general={pi:.5g}")
)
```

Точность применяется к float. Точность для целых и комбинация точности с `s` вызывают runtime error. Для заполнения нулями используй явную пару заполнения и выравнивания, например `0>8d`; ведущий ноль сам по себе является цифрой ширины.

Запусти `examples/v081/02_numeric_formats.rbl` и сравни представления.

**Упражнение:** выведи 4095 в десятичной, двоичной и шестнадцатеричной системах, затем покажи `1/7` с 3, 6 и 12 значащими цифрами.
