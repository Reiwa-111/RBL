# Урок 1: ограниченные спецификаторы f-строк

В RBL 0.8.0 появились ограниченные спецификаторы форматирования. В 0.8.1 они остаются частью языкового контракта. Поле f-строки может задавать символ заполнения, выравнивание, минимальную ширину, точность и тип преобразования.

```rbl
func main() (
    set name = "compiler"
    set count = 42
    set ratio = 3.1415926
    print(f"{name:<12s} {count:>6d}")
    print(f"ratio={ratio:.3f}")
    print(f"hex={255:04X}")
)
```

Грамматика: `[[fill]align][width][.precision][type]`. Выравнивание: `<`, `>` или `^`. Ширина задаёт минимум, а не обрезание строки. Точность float ограничена диапазоном 0–17, ширина — 1 000 000 кодовыми точками. Неверные комбинации вызывают ошибку, а не угадываются компилятором.

Измени ширину и выравнивание, затем выполни `python rbl.py check examples/v081/01_formatting_report.rbl` и `python rbl.py run ...`.

**Упражнение:** создай таблицу из трёх колонок: имена слева, целые значения справа и два знака после точки для вещественных чисел.
