# Урок 6: диагностика компилятора и позиции исходника

Диагностика RBL 0.8.x указывает файл, строку, столбец и этап компилятора. Она включает фрагмент исходника и каретку на сообщённой позиции. UTF-8, табуляции и окончания строк LF/CRLF/CR покрываются regression tests.

Используй `check` перед запуском программы:

```powershell
python rbl.py check examples/v081/01_formatting_report.rbl
```

Чтобы увидеть диагностику, создай временный `.rbl` с неправильным именем функции или некорректным format spec, затем выполни `python rbl.py check path/to/file.rbl`. Команда должна завершиться с ненулевым кодом и указать позицию. Исправь исходник и повтори проверку.

Не считай каждую ошибку ошибкой parser: диагностика различает lexing, parsing, semantic validation и code generation. Runtime error возникает позже, при исполнении уже скомпилированной программы.

**Упражнение:** внеси синтаксическую ошибку и неизвестный идентификатор в два отдельных файла. Сравни метки этапов и позиции исходника.
