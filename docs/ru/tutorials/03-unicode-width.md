# Урок 3: Unicode-ширина и выравнивание

При задании ширины RBL считает кодовые точки UTF-8, а не байты и не экранные ячейки терминала. Широкий CJK-символ или комбинируемая последовательность может занимать другое число ячеек, чем учитывает форматтер.

```rbl
func main() (
    set word = "κόσμος"
    print(f"[{word:*>12s}]")
    set symbol = "λ"
    print(f"[{symbol:·^8s}]")
    print("code points:", len(word))
)
```

Символ заполнения должен состоять ровно из одной кодовой точки Unicode. По умолчанию используется пробел. При центрировании нечётный дополнительный символ заполнения размещается справа. Форматирование с шириной требует корректный UTF-8; без ширины байты строки сохраняются.

Запусти `examples/v081/03_unicode_width.rbl` и посмотри на скобки. Не воспринимай ширину поля как точное выравнивание по пикселям для любого шрифта.

**Упражнение:** выровняй три подписи с ASCII-, греческими и кириллическими символами и сравни `len()` с визуальной шириной в терминале.
