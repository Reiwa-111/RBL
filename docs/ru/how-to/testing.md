## How-to: тестирование RBL

Текущий checkout содержит три дополняющих друг друга уровня проверки: regression suite, smoke-тест стандартной библиотеки и differential runner для двух backend.

## Регрессионные тесты

Из корня checkout:

```bash
python3 tests/run_tests.py
```

В проверенной версии набор содержит 59 прямых тестовых сценариев RBL. Скрипт запускает каждый тест через активный backend и сравнивает код завершения, stdout и заданные диагностические фрагменты.

## Стандартная библиотека и ввод

```bash
python3 tests/test_stdlib.py
```

Этот тест отдельно проверяет глобальные функции и пространства имён стандартной библиотеки, файловый ввод-вывод и интерактивный `input(prompt)`.

## Обе проверки через CLI

```bash
python3 rbl.py test
```

Команда последовательно запускает оба набора, используя пути внутри репозитория RBL. Она не ищет автоматически пользовательские тесты в каталоге каждого RBL-проекта.

## Сравнить Linux и Windows backend

На Windows при наличии WSL и native MinGW-w64:

```powershell
python tests\differential.py --a wsl --b native
```

Параметры `--a` и `--b` выбирают backend; типичные значения — `wsl` и `native`. Можно передать конкретные тестовые пути после параметров. Проверка сопоставляет детерминированное поведение двух реализаций; `cwd`, случайные данные и иные осознанно платформозависимые результаты требуют отдельной трактовки.

## Пересобрать bootstrap toolchain

```bash
python3 rbl.py bootstrap
```

Команда принудительно пересобирает bootstrap compiler/runtime artifacts. Обычно это не требуется: драйвер отслеживает файлы и использует доступные актуальные бинарные компоненты.

## После изменений языка

1. Добавьте минимальный `.rbl` сценарий в `tests/cases/`.
2. Если поведение связано со стандартной библиотекой или вводом — расширьте `tests/stdlib_smoke.rbl` и/или проверки `tests/test_stdlib.py`.
3. Проверьте оба основных набора тестов.
4. На Windows выполните differential test для native и WSL backend.
5. Обновите соответствующие страницы [reference](../README.md#с-чего-начать) и ограничения, если изменился публичный контракт.
