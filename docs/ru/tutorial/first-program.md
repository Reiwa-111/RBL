## Tutorial: первая программа на RBL

Это короткий учебный маршрут для RBL 0.7.2. Он предполагает, что репозиторий уже получен и команды выполняются из его корневой папки. CLI не устанавливается в систему как глобальная команда: используется `rbl.py` из репозитория.

## 1. Проверьте инструменты

Linux:

```bash
python3 rbl.py doctor
python3 rbl.py version
```

Windows PowerShell:

```powershell
python rbl.py doctor
python rbl.py version
```

`doctor` показывает доступность выбранного backend и необходимых инструментов. Для Linux нужны GNU assembler и linker; нативная сборка Windows использует MinGW-w64. На Windows также можно использовать WSL. Подробности — в [инструкции по Windows и WSL](../how-to/windows-toolchain.md).

## 2. Создайте проект

Из корня репозитория:

```bash
python3 rbl.py new hello
cd hello
```

В PowerShell используется та же команда с `python` вместо `python3`.

Команда создаёт `rbl.toml`, `src/main.rbl`, а также каталоги `tests/` и `benchmarks/`. Сам CLI остаётся в исходном репозитории, поэтому из каталога проекта вызывайте его через `../rbl.py` (в PowerShell — `..\rbl.py`).

## 3. Посмотрите на программу

Файл `src/main.rbl` содержит стартовый пример:

```rbl
func main() (
    print("Hello from RBL!")
)
```

Функция объявляется ключевым словом `func`. Круглые скобки после имени содержат параметры, а ещё одна пара круглых скобок ограничивает тело функции. Вызов `print` выводит аргументы через пробел и перевод строки.

## 4. Добавьте вычисления и цикл

Замените содержимое `src/main.rbl` следующим кодом:

```rbl
func square(value int) int (
    return value * value
)

func main() (
    set total = 0

    for (i in 1..=5) (
        let total += square(i)
    )

    print("sum of squares:", total)
)
```

Здесь используются несколько важных конструкций:

- `set` объявляет новую переменную; повторное объявление того же имени в текущей области является ошибкой.
- `let` изменяет уже существующую переменную.
- Параметр `value int` объявлен с типом `int`; `int` после списка параметров задаёт возвращаемый тип.
- Диапазон `1..=5` включает правую границу. Вариант `1..5` её исключает.
- `return` завершает функцию и возвращает значение.

## 5. Проверьте и запустите

Находясь в каталоге `hello`:

```bash
python3 ../rbl.py check
python3 ../rbl.py run
```

`check` проходит компиляторный путь до генерации assembly, но не собирает исполняемый файл. `run` собирает программу и запускает её. В Windows используйте `python ..\rbl.py check` и `python ..\rbl.py run`.

Ожидаемый вывод:

```text
sum of squares: 55
```

## Границы tutorial

RBL 0.7.2 — небольшой компилируемый язык с одним исходным файлом на программу. В нём пока нет `import`, пользовательских модулей, пакетного менеджера, исключений, замыканий и async/await. Полный список ограничений приведён в [справочнике](../reference/limitations.md).
